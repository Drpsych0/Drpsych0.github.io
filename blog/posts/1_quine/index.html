A HTML Quine

A quine is a program that produces its source code as output. With HTML plus CSS (Turing-complete when paired with the DOM), you can make a page that displays its own markup.

The trick

Use ::before and ::after pseudo-elements to inject angle brackets around each tag. Example for paragraphs:

Repeat for html, head, body, headings, tables, and links. For anchors, use attr(href). Escape the slash in </style> as <\/style> so the browser does not close the stylesheet early.

Set * { display: block; } so the embedded CSS block is visible on the page. Use a { display: inline; } so links do not break across lines awkwardly.

To copy the full quine source, print the page and copy from the print preview — pseudo-element content is hard to select in the live DOM.
